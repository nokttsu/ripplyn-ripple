# Ripplyn Ripple

Генератор фирменной графики Ripplyn на приёме «разрез, сдвиг, волна».

**Сайт:** https://noktt.github.io/ripplyn-ripple/ <!-- обновляется при деплое -->

## Приём

Одна исходная картинка режется на вертикальные полосы, и каждая полоса сдвигается по вертикали синусом от точки удара, как круги от камня на воде. Метод нарезки взят у Герхарда Рихтера (серия Strip), живость цвета у Карлоса Круз-Диеса (Physichromie), волна у Бриджет Райли.

1. **Исходник.** Загруженная картинка (кнопка или drag & drop на канвас), сгенерированный исходник (вертикальный градиент палитры, мягкие радиальные пятна, тонкая линия горизонта) или ASCII-текст.
2. **Нарезка.** N вертикальных полос, N — только степени двойки: 2, 4 … 512.
3. **Сдвиг.** Для каждой полосы:

   ```
   offset = sin(dist·π·freq − t·speed) · amp · (1 − dist·0.5)
   ```

   `dist` — расстояние центра полосы от точки удара по горизонтали, нормированное в 0…1. Пустоты у краёв заполняются растянутым крайним рядом пикселей полосы.
4. **Анимация.** `t` растёт со временем, и волна бежит от точки удара. Клик по канвасу переставляет точку удара.

## Параметры ядра

| Параметр | Диапазон | Смысл |
|---|---|---|
| Полос | 2…512 (2ⁿ) | число вертикальных срезов |
| Амплитуда | 0…40 % высоты | `amp` |
| Частота | 0.25…10 | `freq`, сколько полуволн укладывается от точки удара до края |
| Скорость | 0…4 рад/с | `speed` |
| Точка удара, X | 0…1 | центр волны, также ставится кликом |

## Эффекты

Эффекты — стек слоёв поверх ядра, применяются в порядке реестра:

| Эффект | Что делает | SVG |
|---|---|---|
| Blur полос | вертикальный motion blur, пропорциональный скорости полосы | — |
| Mirror | Рихтер: зеркалит полосы, симметрия половин или узкие срезы растягиваются в горизонтальные полосы | flip / через одну |
| Phase color | Круз-Диес: цвет полос бежит по палитре от времени и курсора | ✓ |
| Перекраска в палитру | gradient map: яркость → 2–4 цвета палитры | — |
| Halftone / dither | Bayer 4×4 и 8×8, Floyd–Steinberg, растровые точки; цвета из палитры | — |
| ASCII-арт | результат в символы: свой набор символов, размер ячейки, цвета | — |
| ASCII-оверлей | свой ASCII-арт текстом поверх, можно «по волне» | без «по волне» |
| Grain / noise | зерно: тайлы шума с режимом наложения | — |

Палитра строгая: slate `#556B80`, off `#FBFAF7`, deep `#181D21`, signal `#489FC6`. Все цвета эффектов выбираются из неё или из её градиентов.

## Экспорт

- **PNG** — 1x / 2x / 4x от базовых 1280 px по длинной стороне. Размер ограничен 16,7 Мп, это лимит canvas в Safari.
- **Видео** — WebM (VP9/VP8) через `MediaRecorder` + `canvas.captureStream()`, 3–10 с, 720p или 1080p. Если браузер не пишет WebM, запись идёт в MP4.
- **SVG** — каждая полоса — `<rect>` с вертикальным градиентом, снятым с колонки исходника. Доступно, когда включены только эффекты с SVG-версией.
- **Ссылка** — все настройки, кроме загруженной картинки, лежат в `#s=…` адреса (base64url от JSON, только отличия от дефолта). Адрес обновляется сам, кнопка копирует его.

## Производительность

- Ядро — это `drawImage` на каждую полосу. На 1920×1080: 64 полосы ≈0,1 мс за кадр, 512 полос ≈0,7 мс.
- Пиксельные эффекты (`heavy: true`) работают через `getImageData`. Dither и ASCII считаются на уменьшенной сетке: пиксель или ячейка → одна выборка. Глифы ASCII рисуются из заранее отрендеренного атласа.
- Превью ограничено 1920 px по длинной стороне. При включённых тяжёлых эффектах цикл адаптивно пропускает кадры по скользящему среднему времени рендера, чтобы интерфейс не подтормаживал.
- Все размеры в эффектах задаются в единицах «пикселя при 1280 px», поэтому превью и экспорт в любом разрешении выглядят одинаково.
- `prefers-reduced-motion: reduce` → тул стартует на паузе.

## Как добавить эффект

1. Создайте `src/engine/effects/myEffect.ts`:

   ```ts
   import type { EffectModule } from '../types'
   import { num } from './util'

   export const myEffect: EffectModule = {
     id: 'myEffect',
     name: 'Мой эффект',
     description: 'Одна строка для панели.',
     heavy: false, // true, если читаете пиксели
     params: [
       { key: 'amount', label: 'Сила', type: 'range', min: 0, max: 1, step: 0.01, default: 0.5 },
       // типы: range | switch | select | color | ramp | text
     ],
     apply(fc, p) {
       // fc.ctx — канвас с результатом предыдущих слоёв
       // fc.strips — полосы со смещением и скоростью, fc.t — время, fc.pointer — курсор,
       // fc.unit — масштаб относительно 1280 px, fc.scratch(name, w, h) — переиспользуемые канвасы
       fc.ctx.globalAlpha = num(p, 'amount')
     },
     // необязательно: svg(sc, p) => фрагмент SVG | '' (нет видимого эффекта) | null (нельзя в SVG)
   }
   ```

2. Добавьте его в массив `EFFECTS` в `src/engine/effects/index.ts`. Позиция в массиве — это позиция слоя.

Панель настроек, Randomize, ссылка-состояние и блокировка SVG подхватят эффект автоматически: панель строится из `params`.

## Структура

```
src/engine/
  palette.ts      цвета и градиенты палитры
  source.ts       исходники: сгенерированный, картинка, ASCII
  ripple.ts       ядро: расчёт полос и отрисовка со сдвигом
  renderer.ts     конвейер: исходник → полосы → стек эффектов
  effects/        один файл — один эффект, реестр в index.ts
  state.ts        состояние, пресеты, randomize, URL
  export.ts       PNG, видео, SVG
src/ui/           превью и панель на HeroUI v3
```

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173/ripplyn-ripple/
npm run build
```

Стек: Vite, React 19, TypeScript, HeroUI v3, Tailwind CSS v4, Canvas 2D. Деплой: GitHub Actions → GitHub Pages при пуше в `main`.
